# BPM ⇆ Milliseconds · Forge Minimal

Compact utility designed for the Forge dashboard.

- Type a BPM: milliseconds update immediately.
- Type milliseconds: BPM updates immediately (valid range 20–300 BPM).
- Select note length and straight/dotted/triplet timing.
- Tap the highlighted button twice or more to estimate BPM, or press Space outside inputs/buttons.
- Copy the current milliseconds value.

Standalone HTML/CSS/JS, no libraries or network required. Use `window.ForgeBpmMilliseconds.destroy()` before unloading this module from an SPA dashboard. Scoped `bm-` class/ID naming. Chrome/Firefox/Safari compatible.
