# Kaleidoscope Studio · Forge V3

Four-color circular polyrhythm sequencer with four percussion synthesizer cards.

- Four rhythms share the same four-beat measure. Each ring contains d editable beat points, so 3:4:5:7 means 3, 4, 5 and 7 triggers per bar.
- Per voice: select from nine percussion/synthesis sounds, Pitch, Decay, Tone, Level, Mute, Listen, and All steps.
- Preset, BPM, Master, Randomize, Reset steps.
- Native Web Audio synthesis with ahead-of-time scheduling, without a CDN dependency.
- `window.KaleidoscopeForge.destroy()` stops audio and animation for Forge navigation.

Open `index.html` with a local development server or host the folder on a website. Audio requires a user gesture to start.
