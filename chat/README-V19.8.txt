FORGE CHAT V19.8 — DRAGGABLE WINDOW + 37-TOOL KNOWLEDGE
========================================================

INSTALLATION
1. Keep a backup of your currently working Forge/chat/ folder.
2. Replace only the Forge/chat/ folder with chat/ from this ZIP.
3. Keep your Forge V19.4 index.html, tools and Cloudflare setup unchanged.

DRAGGING
- Open Forge Chat as before.
- Hold the chat title bar (Forge Chat / tool context) and drag it with
  your mouse or finger to another location on the screen.
- The position stays where you leave it while navigating tools and
  closing/reopening the chat within the same page.
- The chat stays fully inside the browser window, including after resize.
- Double-click the title bar to restore its default sidebar position.
- The close button, suggested questions, chat messages, scrolling,
  animated typing indicator and FAQ continue to work as before.
- Refreshing the page resets the position to the usual location.

CONTENTS
- All 37 tool knowledge sheets from V19.7 are unchanged.
- Tool-specific suggestions and all local FAQ logic are unchanged.
- Feedback / ratings still need the separate Cloudflare backend.
- Does not change the visual or sizing behavior of tools in Forge.
