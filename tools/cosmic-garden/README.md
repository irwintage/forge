# Cosmic Garden · Forge V3

## Overview
Scale-driven morphologies, refined minimal Forge/Knot interface, real-time 3D blooms and retained Web Audio instrument.

## Audio scales + visual identities
- Maj Ambient → Radial Bloom
- Lydian → Celestial Helix
- Dorian → Twin Currents
- Minor → Nocturnal Canopy
- Japanese Pentatonic → Five Lanterns

Original five musical scales remain unchanged. Switching scale animates node positions and updates branch connections while preserving the existing interaction and audio engine. Click seeds to play chords. The visual reaction now travels along branches, without expanding circle ripples. Drag to orbit and scroll to zoom (accelerated).

## Files
- index.html
- cosmic-garden.css
- cosmic-garden.js

Three.js 0.158.0 loads from jsDelivr; internet connection required. Open index.html in a modern WebGL-capable browser. Audio starts after a user gesture. Record captures performed note events and renders an offline WAV, not a real-time system-audio capture.

## Quality check
JavaScript syntax, DOM references and ZIP integrity checked. Interactive rendering and audio must still be tested in your own browser.
